The prices went down

Figure 3
Claude Opus list price, output tokens
Dollars per million output tokens. A 67% cut in November 2025, unchanged across four model generations since.

Batch processing takes another 50% off and prompt caching cuts cached input by 90%. Opus 4.5 also emitted roughly 76% fewer output tokens for equivalent work, so cost per finished task fell further than the headline rate. Verify current rates against Anthropic's pricing page before publishing.

Opus 5 costs 89× DeepSeek V4 Pro and 5.7× GLM-5.2 per output token. Capability is not equivalent and the comparison narrows on cost-per-task ($0.04 for V4 Pro, $0.32 for GLM-5.2, $0.94 for Kimi K3). Chinese labs may also be pricing below cost on domestic silicon. The gap narrows. It does not close.

The light Pro user runs a 94% margin. The heavy Max 20x user loses Anthropic roughly $197 a month. The $1,588 figure is a single tracked case reported by a power user; $600–$1,500 is the commonly reported band. Anthropic publishes no token quotas for any plan, only multipliers, so none of this can be checked from inside the product.
