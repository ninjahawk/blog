# NinjaHawk's Nest

Source for [blog.nathanlangley.dev](https://blog.nathanlangley.dev). It's a static site of plain HTML and one shared stylesheet (`style.css`), served by GitHub Pages. There's no build step.

- `index.html`: the homepage feed
- `posts/`: one HTML file per post
- `nest.js`: pull-to-refresh on touch devices
